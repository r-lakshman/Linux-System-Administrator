# Linux Terminal Keyboard Shortcuts

A practical reference for useful keyboard shortcuts when working with commands in the Linux terminal.

These shortcuts help with command-line editing, navigation, command history, process control, and terminal management.

---

## 📚 Topics Covered

- Command-line navigation
- Deleting text and words
- Moving between words
- Command history navigation
- Searching command history
- Stopping and suspending commands
- End of input / EOF
- Clearing the terminal screen
- Undoing command-line changes
- Swapping characters
- Reusing arguments from previous commands

---

## ⌨️ Keyboard Shortcuts

### Command-Line Navigation

| Shortcut | Purpose |
|---|---|
| `Ctrl + A` | Move to the beginning of the command |
| `Ctrl + E` | Move to the end of the command |
| `Alt + B` | Move backward one word |
| `Alt + F` | Move forward one word |

---

### Deleting and Editing

| Shortcut | Purpose |
|---|---|
| `Ctrl + U` | Delete from cursor to beginning |
| `Ctrl + K` | Delete from cursor to end |
| `Ctrl + W` | Delete the previous word |
| `Ctrl + H` | Delete the previous character / Backspace |
| `Ctrl + Y` | Paste previously deleted text |
| `Ctrl + _` | Undo the previous editing action |
| `Ctrl + T` | Swap characters around the cursor |

---

### Command History

| Shortcut | Purpose |
|---|---|
| `↑` | Show the previous command |
| `↓` | Move to the next command |
| `Ctrl + R` | Search command history |
| `Alt + .` | Insert the last argument from the previous command |

---

### Process Control

| Shortcut | Purpose |
|---|---|
| `Ctrl + C` | Stop or cancel a running command |
| `Ctrl + Z` | Suspend a running command |
| `Ctrl + D` | End input / send EOF |

---

### Terminal Management

| Shortcut / Command | Purpose |
|---|---|
| `Ctrl + L` | Clear the visible terminal screen |
| `clear` | Clear the terminal display |
| `history -c` | Clear Bash command history |
